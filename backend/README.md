# Backend магазина техники

Backend на Node.js и Express с локальной базой данных SQLite.

## Запуск

Требуется Node.js 24 или новее. Из папки `backend` установите зависимости и запустите сервер:

```powershell
npm.cmd install
node server.js
```

При первом запуске сервер создаёт `data/store.sqlite` и добавляет примеры категорий и товаров. Файл базы хранится локально и не отправляется в GitHub; таблицы создаются автоматически при запуске.

## API

- `GET /api/products` — список товаров.
- `GET /api/products/:id` — товар по номеру.
- `GET /api/categories` — категории.
- `POST /api/orders` — создать заказ.

Пример тела запроса для заказа:

```json
{
  "customerName": "Имя покупателя",
  "phone": "+996 555 000 000",
  "address": "Адрес доставки",
  "items": [
    { "productId": 1, "quantity": 1 }
  ]
}
```

Пока в проекте нет панели администратора, авторизации и подключения платёжного сервиса. Каталог содержит демонстрационные товары.
